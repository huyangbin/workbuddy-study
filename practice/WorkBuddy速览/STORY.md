# STORY.md · WorkBuddy 功能速览

## ① 用户意图对齐

- **目标受众**：刚接触 WorkBuddy 的学习者 / 想快速了解能力边界的潜在用户。
- **核心目标**：3 页内讲清"WorkBuddy 能干什么 + 怎么工作"，让人记住"本地化、多模态、可扩展"。
- **PPT 长度**：3 页（封面 + 核心能力 + 工作模式）。
- **视觉调性**：科技未来感 / 克制深色 / 蓝青渐变。
- **内容边界**：只讲"能力概览"与"三种模式"，不展开技能创建、自动化 rrule 等进阶细节（留待后续学习章节）。

## ② 页面布局骨架

| # | 类型 | 角色 | rhythm | 版式 | 说明 |
| :- | :--- | :--- | :--- | :--- | :--- |
| 01 | cover | hero | peak | 全屏视觉+骑线文字 | 深色底 + 几何光晕 + 左对齐大标题 |
| 02 | content | supporting | valley | 左标题+右内容 | 左侧色块标题栏 + 右侧六宫格能力清单 |
| 03 | content | supporting | transition | 非对称双栏 | 左 35% 模式总览 + 右 65% 三模式栈 |

- Hero 占比：1/3 ≈ 33%，封面默认 hero，合规。
- 非对称版式：3/3 = 100% ≥ 40%。
- 相邻版式均不同（全屏视觉 / 左标题+右内容 / 非对称双栏），无重复。

## ③ 页面大纲

### 01 · 封面（hero）
- title: WorkBuddy 功能速览
- 主视觉：深色科技底 + 蓝青渐变光晕 + 细网格。
- 文案：主标题"WorkBuddy"渐变字 + "功能速览"白字；副标题"本地化 · 离线可用 · 多模态 · 可扩展的 AI 工作伙伴"。
- anti_pattern: 禁止装饰小图贴标题栏；禁止四卡片。

### 02 · 核心能力（supporting）
- title: 核心能力
- 六模块（图标 + 标题 + 一句描述）：
  1. 文件与命令 — folder：读写文件、运行脚本、管理本地项目
  2. 智能体编排 — users：Explore/Plan/通用代理分工协作
  3. 技能系统 — cogs：加载领域技能，也可自建复用
  4. 自动化 — clock：定时跑流程：一次性 / 周期任务
  5. 多模态生成 — image：文生图 / 视频 / 3D 与内联图表
  6. 三层记忆 — database：云 / 用户 / 项目记忆跨会话延续
- anti_pattern: 禁止把六模块做成等宽四卡；禁止每个卡片只放一个词。

### 03 · 工作模式（supporting / transition）
- title: 三种工作模式
- 左栏：大号"3" + "WorkBuddy 的工作模式"总览。
- 右栏三行：
  - Agent（rocket）：直接执行 — 读文件、跑命令、产出结果
  - Plan（map）：先规划 — 拆解步骤，确认后再动手
  - Ask（comment）：只回答 — 只读不写，给分析与建议
- anti_pattern: 禁止三栏等宽卡片横排；禁止把模式描述写成一句话带过。
