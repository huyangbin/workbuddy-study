## 画布与母版（A/B/C 三区）

| 母版区 | 垂直位置 | 高度 | 规则 |
| :--- | :--- | :--- | :--- |
| A · 标题块 | 0–120px | 120px | 主标题 32–40px bold |
| B · 内容区 | 120–660px | 540px | 正文 / 卡片 / 图标 |
| C · 页脚条 | 660–720px | 60px | 左项目名 + 右页码 `NN / 03` |

- 画布：**1280 × 720**（16:9）。
- 安全区 padding：左右 80px，上下按区块分配。
- 封面（01）使用自定义全屏版式，省略 C 区。

## 色彩池（≤ 4 hex）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 背景主色 | `#0F172A` | 深海军蓝底 |
| 主色 | `#3B82F6` | 蓝（标题渐变起点 / 图标） |
| 辅色 | `#06B6D4` | 青（标题渐变终点 / 强调） |
| 文本 | `#F8FAFC`（主）/ `#94A3B8`（次） | 白 / 灰蓝 |

- 渐变：`linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)`
- 卡片底：`rgba(255,255,255,0.04)`，边框 `rgba(255,255,255,0.08)`
- 强调色（蓝青渐变）仅出现在标题、图标、焦点元素，占比 ≤ 15%。

## 密度与留白

- 常规页留白 ≤ 35%；封面留白可至 40%（围绕标题）。
- 每页 ≥ 1 个视觉锚点：封面=渐变大标题；02=图标矩阵；03=巨型"3"。

## 视觉风格声明

- 全篇统一深色科技风；图标全部用 FAIcon（实心、圆角容器），不混用 Emoji。
