# DESIGN · WorkBuddy 学习教程 PPT

## 主题：暗色科技风（通用/技术分享型）
画布 1280×720，安全区 padding 56px 64px。

## 设计令牌
- 背景：`#0B1020`（主）/ `#0F172A`（卡片底）
- 主色渐变：`linear-gradient(135deg,#3b82f6 0%,#8b5cf6 100%)`（蓝→紫）
- 辅助色：`#22d3ee`（青）、`#34d399`（绿，用于"已完成"标记）
- 标题文字：`#F1F5F9`；正文：`#CBD5E1`；弱化：`#94A3B8`
- 卡片背景：`rgba(255,255,255,0.04)`；卡片描边：`rgba(255,255,255,0.08)`
- 强调条（左侧竖条）：`linear-gradient(180deg,#3b82f6,#8b5cf6)`，宽 8px

## 版式
- **封面/章节页**：大号渐变标题 + 内联 SVG 装饰光晕
- **内容页**：左上强调竖条 + 大标题（34px）→ 下方卡片区（2–3 列 flex 均分）
- **卡片**：圆角 12px，半透明底 + 细描边，内含色点/小 SVG 图标 + 粗体标签 + 说明文字
- **层级标签**（L0–L10）：圆角胶囊，主色渐变底，白字

## 字体
- 标题 30–48px bold；卡片标签 17px bold；说明 14–15px；弱化 12–13px
- lineHeight 1.5–1.6

## 约束
- 高度固定 720px，内容不溢出；不使用 grid/calc；图标用内联 `<svg>`（FAIcon 本环境不可用）
- 渐变文字用 `backgroundClip:'text'` + `color:'transparent'`
