# 工具速查卡 · 任务类型 → 推荐工具

> L2 练习产出。遇到任务先查这张表，再决定用哪个工具。
> 原则：**先找 Skills 再硬刚；大范围探索交给 Agent 子代理；简单读写用专用工具而非 Bash。**

## 一、文件与命令

| 任务类型 | 推荐工具 | 关键说明 / 易错点 |
| --- | --- | --- |
| 读取/查看文件内容 | `Read` | 图片、PDF、ipynb 也能读；长文件可 `offset`/`limit` |
| 新建或整体覆盖写文件 | `Write` | 写已存在的文件前必须先 `Read` |
| 精确修改文件某一段 | `Edit` | `old_string` 必须与磁盘内容**逐字符一致**；新旧相同会报错 |
| 按文件名/通配符找文件 | `Glob` | `**/*.js` 这种，只匹配路径，**不读内容** |
| 按内容/正则搜索文件 | `Grep` | 搜内容用这个；`-n` 行号、`-i` 忽略大小写、`multiline` 跨行 |
| 跑 shell 命令 / 脚本 | `Bash` | 走 Git Bash（POSIX 语法）；长任务用 `run_in_background` |
| Windows 专用 / PowerShell cmdlet | `PowerShell` | 注册表、COM、`.ps1` 逻辑；别用 `&&`/`?:`(需 7+) |
| 验证/managed 运行环境 | `Bash` + 绝对路径 | 调 Python/Node **必须写完整绝对路径**，别裸 `python` |

## 二、智能体编排

| 任务类型 | 推荐工具 | 关键说明 / 易错点 |
| --- | --- | --- |
| 大范围/开放式探索代码库 | `Agent(Explore)` | 自主多轮搜索，**省主上下文**；比手工 Grep 适合"摸清架构" |
| 多步复杂、需自主完成的任务 | `Agent(general-purpose)` | 给自包含、带文件路径的 prompt |
| 只规划不改动的实现方案 | `Agent(Plan)` | 只读设计，返回步骤与关键文件 |
| Excel/表格读写分析 | `Agent(sheet-agent)` | 传完整 `local_path` 或 `file_id` |
| 拆分并跟踪多步任务 | `TaskCreate/Update/List` | 3 步以上、可独立验证时必用；状态 pending→in_progress→completed |

## 三、自动化与任务回收

| 任务类型 | 推荐工具 | 关键说明 / 易错点 |
| --- | --- | --- |
| 指定未来某时刻做一次 | `automation_update`(once) | `scheduledAt` 用 ISO8601 |
| 周期/重复执行 | `automation_update`(recurring) | 必须 `rrule`；FREQ 显式 + 各频率必填字段 |
| 回收后台任务输出 | `TaskOutput` | `block=true` 等待完成；或等系统通知 |
| 提示词自包含 | — | 未来运行**看不到本次对话**，细节全写进 prompt |

## 四、研究与联网

| 任务类型 | 推荐工具 | 关键说明 / 易错点 |
| --- | --- | --- |
| 查最新事实/当下信息 | `WebSearch` | 现世事实必须先搜再答 |
| 抓取并解析某网页内容 | `WebFetch` | 重定向到别的主机要重新 fetch；媒体/二进制用 Bash 下载 |
| 查历史对话/记忆 | `conversation_search` | 只查特定过去事件，不查通用偏好 |

## 五、可视化、交付与扩展

| 任务类型 | 推荐工具 | 关键说明 / 易错点 |
| --- | --- | --- |
| 内联图表 / 图示 / 表单 | `read_me` + `show_widget` | SVG 用 `viewBox="0 0 680 ..."`；HTML 别包 `<html>/<body>`；先 `read_me` 加载模块 |
| 交付结果 / 打开预览 | `present_files` | 每次任务结束的"交付入口"；HTML 自动开预览 |
| 调用技能 | `Skill` | 匹配即优先加载，调用前勿空谈 |
| 调用未知 schema 的延迟工具 | `ToolSearch` → `DeferExecuteTool` | 先搜 schema 再执行 |
| 发现 / 安装技能 | `find-skills` / marketplace | 平台或专业任务先找 Skills |

## 决策速记

- **Glob vs Grep**：找"文件在哪"用 Glob；找"内容写了啥"用 Grep。
- **手工 Grep vs Agent(Explore)**：目标明确、单次查找 → 手工；跨目录、多命名约定、要综合判断 → 交给 Explore 子代理。
- **Bash vs 专用工具**：读/搜/改文件优先用 Read/Grep/Edit，体验更好、更安全，别习惯性 `cat|grep`。
- **一次性 vs 周期自动化**：只做一次 → once；重复 → recurring + rrule。
- **Skill 优先**：遇到平台/专业任务，先 `find-skills`，不要从零硬写。
